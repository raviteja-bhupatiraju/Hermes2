The MedBiquitous Standards

MedBiquitous develops XML standards for health professions education (several of them ANSI standards). Hermes 2 edits the published versions of all of them that have XML schemas. Each document type gets form pages, the document tree, the XML page, validation against the published schemas and the standard's rules, search, comparison and help.

Supported standards and versions

StandardVersionRoot elementWhat it describes
Healthcare LOM1.0lom Learning resources: continuing-education courses and activities with credits and accreditation, medical images and other assets. Also stored in a JSON form.
Curriculum Inventory1.0, and "v10" (the AAMC 2022 point release)CurriculumInventoryA program's curriculum: events, expectations (competencies), academic levels and the sequence of blocks; exchanged with the AAMC Curriculum Inventory.
Competency Framework1.0CompetencyFramework A set of competencies and the relations between them.
Competency Object1.0CompetencyObject A single competency, objective or outcome.
Performance Framework1.0PerformanceFramework Levels of performance (scales, milestones) for competencies.
Activity Report1.0, 2.0ActivityReports Participation in and completion of continuing-education activities, with credits.
Medical Education Metrics (MEMS)1.0, Survey Items 1.0 MedicalEducationMetrics, SurveyItemsOutcomes of education activities: participation, evaluation, knowledge assessment; the standard survey items.
Healthcare Professional Profile1.0 MembersHealthcare professionals: names, contact information, education, licensure, certification and more (with the Name and Address schemas).
Virtual Patient1.0VirtualPatientData, ActivityModel, DataAvailabilityModelVirtual patient cases: the patient data, the paths through the case and which data each step shows.

Not included

  • Working drafts that MedBiquitous never published as standards: Healthcare LOM 2.0, Curriculum Inventory 2.0, Professional Profile 2.0, Disclosure of Interests 1.0 and MEMS 2.0.
  • Disclosure of Interests 2.0 and Educational Achievement 1.0: their schemas import schemas that are no longer published (MedBiquitous Common 3 and the PESC Core Main 1.12.0 and Academic Record 1.7.0 schemas), so they cannot be validated. They will be added when those schemas are available again.
  • Educational Trajectory (a profile of the LEAP2A Atom format) and xAPI, which have no XML schemas of their own, and the web service descriptions (WSDL).

Working with documents of any standard

  • New documents: File > New Document (or the start page) asks for the standard; each starts from a template that is already valid.
  • Opening: the editor recognizes a document by its root element and namespace, whatever its file name.
  • Editing: the overview shows the title, the standard and version, the parts of the document and the validation results; the form pages follow the structure of the standard; the document tree and the XML page (with content assist from the schemas) show everything.
  • Validation: in the editor, in the Problems view for the documents of projects, with hermes validate on the command line and in other editors through the language server: the same schemas and rules everywhere, offline.
  • Search and compare work for all standards; the Search dialog offers the field groups of each standard.
