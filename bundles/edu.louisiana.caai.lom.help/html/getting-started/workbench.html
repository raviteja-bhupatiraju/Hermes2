A Tour of the Workbench

The Hermes 2 window is an Eclipse workbench: an editor area surrounded by views that you can move, stack, minimize and close.

Default layout

AreaContents
LeftProjects view: your projects, their folders and documents with titles and validation state.
CenterThe editor area. While no document is open, the Start page is shown in its place.
RightOutline (top) and Properties (bottom). The HLOM Guide opens stacked with the Outline.
BottomValidation, Problems and Library; the Search view opens here too. The Compare view opens below the editor.

The main tool bar holds: New MedBiquitous Document (which opens the new-document wizard for any standard), Open, Save, Undo, Redo, Validate (shows the Validation view and validates the active document), Show the metadata library, Create records from the rows of a CSV file, Export the active record as an HTML catalog card and Open the HLOM Guide. Further buttons are contributed next to it: Compare With Saved Version and, while a document is active, Add MeSH Keywords.

The status bar shows the memory in use; click its trash-can icon to run the garbage collector.

The editor

Each document opens in one editor with several pages that all edit the same document. Hermes 2 recognizes the standard of a document by its root element and namespace, whatever the file name, and shows the pages of that standard. A navigation sidebar on the left lists the pages in groups, with a badge counting the problems of each page. For a Healthcare LOM record these are:

  • Overview: summary dashboard.
  • Description: General, Life Cycle, Educational, Rights, Classification, Relation, Annotation.
  • Healthcare: Healthcare Education, Healthcare Asset (the MedBiquitous extensions, marked with a teal accent).
  • Record: Meta-Metadata, Technical.
  • Source: Document Tree, XML, JSON.

Documents of the other MedBiquitous standards have an Overview page (title, standard and version, the parts of the document and the validation results), the form pages defined for their standard (for example the events, expectations and sequence of a Curriculum Inventory), and the Document Tree and XML pages. They have no JSON page.

All pages share one undo/redo history (Ctrl+Z, Ctrl+Y), and merely viewing a document never changes it. Clearing a field removes elements that became empty.

Workspace and window state

Preferences, open projects and the window layout are kept in the workspace folder ~/.hermes2/workspace (in your home folder), so Hermes 2 also runs from a read-only installation folder. The workspace is refreshed automatically when files change outside the application.

Besides the default perspective, Hermes 2 defines a Library perspective that shows the metadata library across the top with the editor and the validation below it.
