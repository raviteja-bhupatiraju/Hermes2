Views

Views surround the editor and show information about your projects and the active document. Most can be opened from the Window menu, the main tool bar or the commands described below. Press F1 in a view for its context help.

Projects

Your projects with their folders and documents of every MedBiquitous standard. Documents are shown with their titles and an icon for their validation state; tooltips show the file location, the format and the number of errors and warnings, and for a project its description, location, document counts and the format of new documents.

  • Tool bar: New Project…, Open Project…, New Document…, Add Existing Documents…, Refresh.
  • View menu: New Project…, Open Project…, Collapse All, Refresh.
  • Context menu: Open, New Document…, Add Existing Documents…, New Folder…, Convert to JSON, Convert to XML (Healthcare LOM), Rename…, Delete, Show in File Explorer, Properties…, Close Project, Refresh.
  • Keys: Enter opens, F2 renames, Delete deletes, F5 refreshes. Files can be dropped on the view to add them.
  • Open: Window > Show Projects.

See Creating and Opening Projects.

Outline

The element tree of the active document. Selecting an element selects it in the editor and shows its attributes in the Properties view.

Properties

The attributes of the element selected in the Document Tree or the Outline, editable in place. Also opened with Show Properties View in the Document menu.

Validation

The problems of the active document, of any standard: columns for the quick-fix light bulb (Healthcare LOM), Description, Element, Line and Check.

  • Tool bar: Fix All, Validate Now.
  • Context menu: Quick Fix (submenu), Quick Fix… (Ctrl+1), Fix All…, Go to Element, Copy Message, Validate Now.
  • Double-click a problem to show its element.
  • Open: Validate on the main tool bar.

See Validating and Fixing Problems.

Problems

The standard Eclipse Problems view. It lists the background validation markers (type Healthcare LOM Problem) of all documents of your projects, of every standard, kept up to date whenever documents change. Problems are shown at their lines in the files as written. Double-click a problem to open the document at the field concerned. The view can be filtered, sorted and grouped with its view menu.

Library

The metadata library: all MedBiquitous documents below a folder, with statistics, search, filter chips (kind and status) and sortable columns (status, Title, Kind, Credits, Audience, Modified, Errors, Warnings, Complete, File). For documents of standards other than Healthcare LOM, the Kind column shows the standard; credits, audience and completeness are Healthcare LOM columns.

  • Tool bar: Choose Folder…, Refresh, Export Library Report….
  • Context menu: Open, Validate Again, Export HTML Card…, Reveal in Explorer, Copy Path.
  • Open: Window > Show Library or the main tool bar.

See The Library and HTML Reports.

Compare

A field-by-field comparison of two documents of the same standard, with the columns Field, Left and Right and a filter. Healthcare LOM records are grouped by category and compared semantically; documents of the other standards are compared by element path and grouped by the parts of the root element.

  • Tool bar: Show Unchanged Fields, Expand All, Collapse All, Swap Left and Right, Refresh (Re-read Files), Copy Differences as Text.
  • Open: File > Compare.

See Comparing Documents.

Search

The results of Search > Search Documents… (Ctrl+H): matching fields grouped by project and document, with the matches highlighted. Double-click a field to open the document with the field selected. See Searching Documents.

HLOM Guide

The in-application guide to Healthcare LOM (only) and the editor: categories and elements, the healthcare extensions, vocabularies, the conformance checklist, credit acronyms, professions and specialties, and how to use the editor, with a search. It opens stacked with the Outline.

  • Tool bar: Back, Forward, Overview, Print, Open in Web Browser.
  • Open: Help > HLOM Guide, the main tool bar, or Shift+F1 (Help > Show Field in HLOM Guide) to show the topic of the focused field.
  • If no embedded browser is available, the view offers to open the guide in your web browser.

You can also open the guide here: HLOM Guide.

Help

The Eclipse Help view. F1 (Help > Context Help) shows the context help of the focused field, view, editor page or dialog in it, with links to the matching topics of this guide and of the HLOM Guide. It also offers search and the contents of this guide.

Start page

Shown in place of the editor area while no document is open (and with Help > Start Page).

  • The header: “Hermes 2 MedBiquitous Editor” and the tagline “Create, validate and exchange MedBiquitous documents: learning object metadata, curricula, competencies, activity reports, education metrics, professional profiles and virtual patients.”
  • Get started: New document… (a document of any MedBiquitous standard), Open…, New project…, Open sample… (a menu with the Healthcare LOM samples and a submenu of samples for each other standard; samples are copied to Documents\MedBiquitous Samples).
  • Start from a template: one card per Healthcare LOM template, then one card for each other standard.
  • Recent documents, with Clear.
  • The MedBiquitous standards: a short introduction to the standards Hermes 2 edits. See The MedBiquitous Standards.
