Validation Rules and Quick Fixes

Besides the XML Schema and model checks, Hermes 2 applies the HLOM rules below to Healthcare LOM records (check Rules). The second table lists the quick fixes offered for them.

This page covers Healthcare LOM. Documents of the other MedBiquitous standards are checked against their own schemas and rules, which are described in the topics of the standards under The MedBiquitous Standards; they have no quick fixes.

The terminology checks recognize a terminology by its name or common aliases in the source (for example MeSH, MSH, ICD-10-CM, ICD10, ACGME Core Competencies). Sources of other terminologies are not checked.

Schema and model problems

XML Schema problems use the messages of the XML parser (without the cvc-… error codes), for example for misplaced or unknown elements, missing required content or values outside an enumeration. Model problems report data types, patterns and multiplicities; a document without a <lom> root element is reported as “The document has no <lom> root element.”
