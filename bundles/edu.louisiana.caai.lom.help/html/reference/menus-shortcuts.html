Menus and Keyboard Shortcuts

This reference lists the menus of the Hermes 2 main window and its keyboard shortcuts. On macOS, use Command where this page says Ctrl. Shortcuts can be changed in Window > Preferences… > Keys.

File menu

ItemShortcutDescription
New > Healthcare LOM DocumentCtrl+N Opens the new-document wizard, for a document of any MedBiquitous standard.
New > Project…Creates a project.
Open…Ctrl+OOpens a document file.
Open URI…Ctrl+UOpens a document from a URI.
Open Project…Opens a project folder, or makes a folder a project.
Open RecentRecently used documents, and Clear Recent Documents.
Import from CSV…Creates Healthcare LOM records from the rows of a CSV file.
Export as HTML…Saves the active Healthcare LOM record as an HTML catalog card and opens it in the browser.
Compare > Compare With Saved VersionReviews the unsaved changes of the active document.
Compare > Compare With File…Compares the active document with another document of the same standard.
Compare > Compare Two Files…Compares two documents of the same standard field by field.
CloseCtrl+WCloses the active editor.
Close AllCtrl+Shift+W Closes all editors.
SaveCtrl+SSaves the active document.
Save As…Saves under another name; for a Healthcare LOM record, a .json or .xml name converts the document.
Save AllCtrl+Shift+S Saves all modified documents.
ExitCloses Hermes 2.

Edit menu

ItemShortcutDescription
UndoCtrl+ZUndoes the last change. Form pages, tree and views share one history; on the XML page, undo works on the text.
RedoCtrl+YRedoes the last undone change.
Cut, Copy, Paste Ctrl+X, Ctrl+C, Ctrl+V Clipboard operations on text or on selected elements.
DeleteDeleteDeletes the selection.
Select AllCtrl+ASelects all text.

Document menu

Shown while a document editor is active.

ItemDescription
New Child, New SiblingAdd an element below or next to the element selected in the Document Tree or Outline.
Add MeSH Keywords…Healthcare LOM records: opens the MeSH lookup and adds the chosen descriptors as keywords (also on the editor tool bar).
RefreshRefreshes the Document Tree.
Show Properties ViewOpens the Properties view.

The menu may also contain generic commands of the underlying Eclipse Modeling Framework editor (such as Validate, Control… and Load Resource…). Use the Validation view and the main tool bar's Validate to check documents.

Search menu

ItemShortcutDescription
Search Documents…Ctrl+HOpens the Search dialog on the Hermes Document Search page.

Window menu

ItemDescription

(open windows)Switches between open windows.

Help menu

ItemShortcutDescription
User GuideOpens this guide in the Help window.
Search Help…Searches this guide.
Context HelpF1Shows the help of the focused field, view, page or dialog in the Help view.
HLOM GuideOpens the HLOM Guide view.
Show Field in HLOM GuideShift+F1 Opens the HLOM Guide at the topic of the focused field (or its overview).
Specification (PDF)Opens the bundled MedBiquitous Healthcare LOM specification v1.1 with your PDF viewer.

Start PageShows the start page.
