Creating Documents

New documents of any MedBiquitous standard are created with the New MedBiquitous Document wizard. Healthcare LOM records start from one of five templates; documents of the other standards start from the template of their standard. Every template produces a complete, schema-valid document.

Create a document

  1. Open the wizard in one of these ways:
    • File > New > Healthcare LOM Document or Ctrl+N;
    • the New MedBiquitous Document button of the main tool bar;
    • New document… (“Create a document of any MedBiquitous standard”) or a template card on the start page; the card of another standard opens the wizard with that standard chosen;
    • New Document… in the Projects view (creates the document in the selected project folder, in the project's format).
  2. Choose the Standard at the top of the wizard: Healthcare LOM 1.0 (learning object metadata), or one of the other standards and versions (for example Curriculum Inventory v10 (AAMC 2022) or Activity Report 2.0); see Documents of the other standards.
  3. Under Start from, click a template (for Healthcare LOM, see the table below; another standard shows the single card of its template).
  4. Enter the Title. It can be left empty, but you will be reminded that the document has no title yet.
  5. Check the Language: a language tag such as en-US or fr. It is used as the language of the record and of its text.
  6. Choose the Format: XML (.xml) or JSON (.json). JSON is available for Healthcare LOM only; documents of the other standards are XML.
  7. Check the File (or click Browse…). By default it is in the folder of your most recent document, else in your Documents folder.
  8. Click Finish. The document is created and opened in the editor.

If the file exists, you are asked whether to replace it. A JSON document must use the extension .json; with any other extension it is saved as XML, and the wizard warns you about this.

Healthcare LOM templates

TemplateContents
Blank recordA minimal, conformant Healthcare LOM record with just a title and language.
CME courseAn accredited continuing education course: authors and publisher, learner context, rights, one CME credit entry, physician audience and disclosures.
Medical image assetA medical image (JPEG) with technical format, image learning resource type and the healthcare asset details: image type, orientation and dimensions.
Patient education resourcePlain-language material for patients and caregivers: patient education context, patient audience and a grade 8 reading level.
Live workshopA live conference or workshop session with venue, country and start and end date and time.

Templates contain placeholders such as “Author Name”, “Publishing Organization” or “Venue Name”. Replace them with real values; the Overview page's Next steps point to what is most valuable to add.

Documents of the other standards

When you choose another standard, the gallery shows one card, New standard: a document with the content the standard's schemas require, ready to be completed. The title and language you enter are written into it where the standard has a place for them. The format is always XML (the JSON option is disabled).

Recording yourself as author (Healthcare LOM)

If Add me as author and meta-metadata creator of new documents is selected in Window > Preferences… > Healthcare LOM and your name is entered there, new documents list you as author (Life Cycle) and as creator of the metadata (Meta-Metadata), as a vCard built from your name, organization and email.

Other ways to get documents

  • Samples: Open sample… on the start page copies a sample document to Documents\MedBiquitous Samples and opens it. The menu lists the Healthcare LOM samples first (CME courses with credits and disclosures, a course with several credit types, medical image assets and a live workshop), followed by a submenu of samples for each other standard.
  • Existing files: File > Open… (Ctrl+O), File > Open URI… (Ctrl+U) and File > Open Recent; or add them to a project.
  • Spreadsheets: Import from CSV creates one Healthcare LOM record per row.
