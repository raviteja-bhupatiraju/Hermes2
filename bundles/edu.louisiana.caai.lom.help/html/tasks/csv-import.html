Importing Records from CSV

If your course catalog is kept in a spreadsheet, Hermes 2 can turn it into Healthcare LOM records: one record per row, each validated before it is written.

Prepare the spreadsheet

  • Save it as CSV. Comma, semicolon, tab and vertical bar (|) delimiters and UTF-8, UTF-16 and Windows-1252 encodings are detected automatically.
  • Use the first row for column headers. Headers such as “Title”, “Course Code”, “Credits”, “CME Credits”, “Specialties” or “hx:creditType” are recognized automatically.
  • Separate several values in a cell with ;, for example physician; registered nurse.
  • Credit columns take one value per credit: CME; CNE in the credit type column with 1.5; 2 in the credits column.
  • Tag keywords with MeSH descriptors as Sepsis [MeSH:D018805].
  • Write contributors as Name <email>.

A complete example, samples/import/courses.csv (six fictional courses and assets), is part of the Hermes 2 source repository.

Import

  1. Choose File > Import from CSV… or click Create records from the rows of a CSV file on the main tool bar.
  2. Import from CSV page: choose the File. Check the detected Delimiter and Encoding (change them if the preview looks wrong). Under Start each record from, choose the template every record starts from, set the Default language for rows without a language of their own, and decide whether to Remove template placeholders that no column fills (“Author Name”, “Venue Name”, …). Click Next.
  3. Map Columns to HLOM Fields: columns were matched by their names. Click a field to change the mapping; ignored columns are not imported. Match by Name repeats the automatic matching and Ignore All clears it. Selecting a field shows its help and an example. Click Next.
  4. Review the Records: every row was converted and validated against the HLOM schemas and rules. The table shows each record's status, kind and credits; below it, the Notes tab lists the problems and how values were interpreted, and the XML tab shows the generated record. Uncheck rows you don't want, or use Select All, Select Valid and Select None. Click Next.
  5. Save the Records: choose the Folder and the File names pattern (a preview shows the resulting names). Choose whether to Replace existing files with the same name, Show the folder in the Library afterwards and Open the first record in the editor. Click Finish.

Friendly values

Common spreadsheet values are interpreted, and every interpretation is listed in the notes. For example, “self-paced” becomes the pacing value learner paced, “CT” becomes the medical image type computed axial tomography scan, and “90” in a duration column becomes PT1H30M.

File name placeholders

PlaceholderReplaced by
{title}The record's title
{row}The row number
{n}A running number: 001, 002, …
{id}The record's identifier
{kind}The kind of record
{template}The template
{date}The date
{column:Header}The value of the column with that header

The extension .xml is added; duplicate names get -2, -3, …. Existing files are never replaced unless you select the replace option.

Importable fields

Columns can be mapped to 65 HLOM fields in these groups: General, Life cycle, Technical, Educational, Rights, Classification, Healthcare education, Credits, Target audience, Activity location and Healthcare asset. Each field lists the header names it recognizes, a description and an example in the mapping page.

Imported records are written as XML. For developers: the importer is also registered as the Eclipse import wizard HLOM Records from CSV (category Healthcare LOM).
