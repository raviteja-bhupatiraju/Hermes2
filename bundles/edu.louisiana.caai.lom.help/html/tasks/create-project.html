Creating and Opening Projects

Projects group the documents you work on together: Healthcare LOM records and documents of the other MedBiquitous standards, in any mix. You can create a new project folder or turn any existing folder of MedBiquitous documents into a project.

Create a project

  1. Choose File > New > Project…, click New Project… on the Projects view tool bar, or click New project… on the start page.
  2. In the New Project dialog enter:
    • Name: also the name of the project folder.
    • Location: the folder in which the project folder is created (default: Documents\Hermes Projects). The dialog shows the resulting project folder.
    • Description (optional).
    • New documents: XML (.xml) or JSON (.json). This is the format of new Healthcare LOM records; documents of the other standards are always created as XML.
  3. Click Create.

If the folder already exists, its MedBiquitous documents become documents of the project. If the folder already is a project, use Open Project instead.

Open an existing folder as a project

  1. Choose File > Open Project… or click Open Project… on the Projects view tool bar.
  2. Select the project folder, or any folder of MedBiquitous documents.
  3. If the folder has no project file yet, confirm Make it a project?. Hermes 2 writes hermes-project.json into the folder; the documents are not changed.

Work with documents in a project

Select a project or one of its folders in the Projects view and use the tool bar or the context menu:

ActionWhat it does
New Document…Opens the new-document wizard with the selected folder and the project's format preselected.
Add Existing Documents…Copies documents (*.xml, *.json, *.lom) into the selected folder. Files that aren't documents of a supported MedBiquitous standard are skipped; a copy whose name is taken gets a numbered name such as name-2.xml. You can also drop files on the view.
New Folder…Creates a subfolder.
OpenOpens the selected documents (also Enter or double-click).
Convert to JSON / Convert to XMLWrites the document in the other form and removes the original file. Healthcare LOM only: documents of the other standards have no JSON form.
Rename… (F2)Renames a document or folder. A document keeps its extension; use Convert to change the format. Open editors are closed first.
Delete (Delete)Deletes documents or folders (with all their contents) from the disk after confirmation.
Show in File ExplorerShows the file or folder in the system file manager.
Refresh (F5)Re-reads the folders and validates.
Collapse AllCollapses the tree (view menu).

Edit the project's properties

  1. Right-click the project and choose Properties….
  2. Change the name, the description or the format of new documents, and click OK.

The changes are written to hermes-project.json.

Close a project

Right-click the project and choose Close Project. The project is removed from the Projects view; its files stay on the disk and can be opened again with Open Project….
