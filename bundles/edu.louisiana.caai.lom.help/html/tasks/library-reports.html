The Library and HTML Reports

The metadata library shows all MedBiquitous documents below a folder in one table, with their validation status and, for Healthcare LOM records, their kind, credits, audience and completeness. HLOM records and libraries can be published as printable HTML.

Documents of the other standards are listed with their title and validation status; their Kind column shows the standard (for example Curriculum Inventory). Credits, audience, completeness and the HTML catalog card are Healthcare LOM features.

Open the library

  1. Choose Window > Show Library or click Show the metadata library on the main tool bar.
  2. Click Choose Folder… on the view's tool bar and select the folder that contains your records. The library remembers the folder (also set in Preferences > Healthcare LOM > Library; default Documents\Healthcare LOM).

Records are found and validated in the background; the header shows the progress and then the statistics: the number of records, how many are valid or have warnings or errors, and the credits offered.

Find records

  • Type in the search field to filter by titles, keywords, MeSH IDs, authors and other text.
  • Click the filter chips to show only Offerings, Image assets or Learning objects, and only records with Errors, Warnings or that are Valid.
  • Click a column header to sort: status, Title, Kind, Credits, Audience, Modified, Errors, Warnings, Complete (how completely the record is described) and File.

Work with records

Double-click a record to open it. The context menu offers:

ActionPurpose
OpenOpen the record in the editor.
Validate AgainReload and validate the selected records.
Export HTML Card…Save the selected record as an HTML catalog card.
Reveal in ExplorerOpen the folder containing the record.
Copy PathCopy the file path to the clipboard.

Saving a record in the editor revalidates it in the library. Refresh scans the folder again.

Export a catalog card

A catalog card is a printable one-page HTML summary of a Healthcare LOM record.

  1. Open the record and choose File > Export as HTML… (or click Export the active record as an HTML catalog card on the main tool bar; in the library, use Export HTML Card…).
  2. Choose the file name and folder and save. The card opens in your web browser.

Export a library report

  1. In the Library view, filter and sort the records you want to include.
  2. Click Export Library Report… on the view's tool bar.
  3. Choose the file and save. The report contains the records shown, can be sorted in the browser, and opens in your web browser.

The Library perspective arranges the library across the top with the editor and the validation below it, which is convenient for reviewing many records.
