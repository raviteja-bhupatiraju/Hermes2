Comparing Documents

The Compare view shows the differences between two documents of the same standard field by field. Use it to review your unsaved changes or to compare two versions or two different documents. Healthcare LOM records are compared semantically, by category; documents of the other standards are compared element by element.

Review unsaved changes

  1. In the editor of the document, choose File > Compare > Compare With Saved Version (also on the main tool bar).
  2. The Compare view opens below the editor with the saved file on one side and the editor's current state on the other. It updates as you keep editing and after you save.

Compare the active document with a file

  1. Choose File > Compare > Compare With File….
  2. Select the other document. It must be of the same standard as the active document; documents of different standards can't be compared.

Compare two files

  1. Choose File > Compare > Compare Two Files….
  2. Select two documents in the file dialog (or select one, then choose the second in the next dialog).

Reading the comparison

  • The header names the LEFT and RIGHT side and whether each is a file, the saved version or the editor.
  • The differences are listed in a table with the columns Field, Left and Right; added, removed and changed values are highlighted.
  • Healthcare LOM: differences are grouped by category (General, Life Cycle, Healthcare Education…). The comparison is semantic: repeated elements are matched by meaning (keywords by MeSH ID, credits by credit type, texts by language), so merely reordering elements is not reported as a change.
  • Other standards: the documents are compared field by field by element path, and the differences are grouped by the parts of the root element (for example the events, expectations and sequence of a Curriculum Inventory).
  • Double-click a field to show it in the editor (the document must be open).
  • Type in Filter fields and values to narrow the list.

Compare view tool bar

ActionPurpose
Show Unchanged FieldsAlso list fields that are equal, to review the whole document.
Expand All / Collapse AllExpand or collapse the categories.
Swap Left and RightExchange the sides.
Refresh (Re-read Files)Read the files again.
Copy Differences as TextCopy the differences to the clipboard, for example for a review note.

The view menu also offers the three compare commands.
