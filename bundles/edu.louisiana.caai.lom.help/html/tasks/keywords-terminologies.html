Keywords and Terminologies

Keywords coded with a clinical terminology make records easier to find and to link with other health sciences content. Hermes 2 includes MeSH, ICD-10-CM and several educational taxonomies and searches them offline.

The keyword and terminology tools described here (Add MeSH Keywords, Look Up… and the taxon path lookup) work in Healthcare LOM records. Documents of the other MedBiquitous standards don't offer them.

How coded keywords are stored

A keyword is multilingual text with two optional MedBiquitous attributes: hx:source, the terminology, and hx:id, the code in it. For example:

<keyword hx:source="MeSH" hx:id="D018805">
  <string language="en-US">Sepsis</string>
</keyword>

Hermes 2 writes MeSH or ICD-10-CM as the source. You can also type other sources by hand, for example SNOMED CT or UMLS, which are not included because they require a license of each user.

Add MeSH keywords

  1. With a document open, click Add MeSH Keywords… on the editor tool bar or choose it from the Document menu.
  2. In the Add MeSH Keywords dialog, type at least two characters: a name such as myocardial infarction, or a descriptor ID such as D009203.
  3. Select one or more descriptors (hold Ctrl or Shift to select several). The details pane shows the scope note, tree numbers, entry terms and see-also references. Descriptors that are already keywords of the document are marked.
  4. Click Add Keywords, or double-click a descriptor to add it right away.

The keywords are added to General > Keywords with hx:source="MeSH" and the descriptor ID.

Add MeSH or ICD-10-CM keywords from a keyword list

  1. On the General page (or in a classification), click Look Up… on the tool bar of the Keywords list.
  2. In the Add Coded Keywords dialog, choose the Terminology (MeSH or ICD-10-CM).
  3. Type in Search (names, synonyms or codes, for example sepsis or A41.9), or browse the hierarchy. The details show the hierarchy, definition, synonyms and entry terms, tree numbers (MeSH) and related concepts.
  4. Select concepts and click Add. Concepts that are already keywords with the same source and code are skipped.

Fill a classification taxon path

Classifications record, for example, the competencies or learning outcomes a resource addresses as a path in a taxonomy.

  1. On the Classification page, add a classification and choose its Purpose (for example competency).
  2. Add a taxon path and click Look up in MeSH, ICD-10-CM, ACGME, Bloom's taxonomy or AAMC Curriculum Inventory….
  3. In the Look Up Taxon Path dialog, choose the terminology, find the concept and click Use.

The taxon path's Source is set to the terminology (for example “ACGME Core Competencies”) and its Taxa to the concept's path in the hierarchy, from general to specific, each with ID and entry. For example, the ACGME competency Medical Knowledge has the ID b, as in the specification's examples.

Checks on coded keywords

Validation warns when:

  • a keyword with source MeSH has no descriptor ID, or an ID that is not a MeSH descriptor ID (D followed by 6 or 9 digits);
  • a keyword's code doesn't exist in the included terminology (for example an unknown ICD-10-CM code);
  • a taxon ID is not a code of the terminology named as the taxon path's source.

The Go to MeSH Keyword quick fix shows the keyword concerned.

MeSH descriptors newer than the index

All lookups use the offline MeSH 2026 index. If you work with descriptor IDs introduced after it, you can let Hermes 2 look up unknown IDs with the NLM MeSH service: select Look up unknown descriptor IDs online in Window > Preferences… > Healthcare LOM > MeSH. This is off by default.
