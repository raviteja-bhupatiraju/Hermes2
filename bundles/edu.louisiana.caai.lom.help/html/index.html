Hermes 2 User Guide

Hermes 2: MedBiquitous Editor is a desktop editor for the published MedBiquitous standards of health professions education: Healthcare Learning Object Metadata (HLOM) v1, Curriculum Inventory, Competency Framework, Competency Object, Performance Framework, Activity Report, Medical Education Metrics (MEMS) and MEMS Survey Items, Healthcare Professional Profile and Virtual Patient.

Documents of every standard can be created from templates, edited on form pages, in the document tree or as XML, validated against the standard's published schemas and rules (offline), managed in projects, searched and compared. The same checks run on the command line (hermes validate) and in other editors through the language server.

Healthcare LOM (ANSI/MEDBIQ LO.10.1-2008, the healthcare profile of IEEE LOM 1484.12.1 / 1484.12.3, used to describe continuing-education courses, live activities and medical image assets) has the most complete support: HLOM records can also be stored in a JSON form, repaired with quick fixes, coded with offline terminologies (MeSH, ICD-10-CM and others), scored for completeness, imported from CSV and published as HTML catalog cards and library reports.

Getting help while you work

  • Press F1 to show context help for the focused field, view, page or dialog in the Help view.
  • In a Healthcare LOM document, press Shift+F1 to open the focused field's topic in the HLOM Guide view, the in-application reference to that standard.
  • Hover over a field label to read the specification's description of the element.
  • Use Help > Search Help… to search this guide.
