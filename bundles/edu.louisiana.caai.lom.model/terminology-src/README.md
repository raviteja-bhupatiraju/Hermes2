# Offline terminology indexes

`../terminology/*.tsv.gz` are the terminologies Hermes 2 searches offline (`support/terminology/Terminologies`);
MeSH and ICD-10-CM, which are released every year, are in fragments of their own
(`bundles/edu.louisiana.caai.terminology.mesh` and `.icd10cm`, each with a feature in `releng/`), versioned by the
release of the terminology (2026.0.0), so that a new release is installed with *Help > Check for Updates* without a
new version of the application. They are generated by `build_terminologies.py` from the published sources and
committed, so that the build needs no downloads.

For a new release of MeSH or ICD-10-CM: regenerate the index, raise the version of its fragment and feature
(`MANIFEST.MF`, `feature.xml` and both `pom.xml`, e.g. 2027.0.0), build and publish the update site.

| Index | Source | Download |
| --- | --- | --- |
| `mesh.tsv.gz` | MeSH descriptors (NLM), all descriptors with entry terms, scope notes, tree numbers, see-also | `desc<year>.gz` from <https://nlmpubs.nlm.nih.gov/projects/mesh/MESH_FILES/xmlmesh/> |
| `icd10cm.tsv.gz` | ICD-10-CM (NCHS/CDC): chapters, blocks, categories and all codes, with inclusion terms | `icd10cm-table and index-<year>.zip` and `icd10cm-Code Descriptions-<year>.zip` from <https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Publications/ICD10CM/> |
| `aamc-ci.tsv.gz` | Curriculum Inventory standardized instructional and assessment methods and resource types (AAMC/MedBiquitous, March 2016) | <https://www.medbiq.org/media/3241/download?attachment> (PDF; extract its text with `pypdf`) |
| `acgme.tsv.gz`, `bloom.tsv.gz` | ACGME core competencies (coded a–f as in the HLOM specification's examples, b = Medical Knowledge), revised Bloom's taxonomy | defined in the script |

Regenerate (each source in its own folder):

```
python -I build_terminologies.py --mesh desc2026.gz \
    --icd-tabular "icd10cm-table and index-2026.zip" --icd-codes "icd10cm-Code Descriptions-2026.zip" \
    --aamc vocab2016.txt
```

`vocab2016.txt` is the text of the AAMC PDF:
`python -c "import pypdf,sys; print('\n'.join(p.extract_text() for p in pypdf.PdfReader(sys.argv[1]).pages))" vocab.pdf > vocab2016.txt`
