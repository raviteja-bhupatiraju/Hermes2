# Schema mirror

Snapshot of the published MedBiquitous schemas (`ns.medbiq.org`), plus the W3C and Dublin Core schemas they import.
`tools/schematool` resolves schema locations against this folder.

The sample/toolkit `.zip` archives published next to the schemas (for example `member.zip`,
`healthcarelom.zip`, `professional_profile_implementation_toolkit.zip`) are not kept in the repository. Their
contents are already present here as extracted `.xsd` files; download the archives from
<https://www.medbiq.org/> if you need them. Links to them in `ns.medbiq.org/index.html` are therefore dead.
